# @ggem/ui

Accessible React components for GGEM Farming, built on Base UI and styled with Tailwind CSS v4
and [`@ggem/tokens`](../tokens).

```css
@import 'tailwindcss';
@import '@ggem/ui/styles.css';
```

```tsx
import { Button } from '@ggem/ui';
```

Requires React 18.2+ or 19 and Tailwind CSS 4.1+. See the Storybook for components and usage.
